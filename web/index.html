tui2web / local file playground

A real Rust/Ratatui editor in a WASM Worker. Type or paste Unicode, click a file, use Tab to switch (and save), Ctrl+S to save, Ctrl+N to create. Shift+drag selects terminal text. Save is acknowledged only after IndexedDB commits. Unsaved edits are lost on restart.

Trust boundary: the default demo loads our trusted module. The isolated option runs app glue in an opaque-origin, network-denied Worker; the parent only stores validated virtual-file snapshots. No shell, backend or native filesystem.
